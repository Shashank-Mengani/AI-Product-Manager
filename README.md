# HackathonPM.ai 🚀

**HackathonPM.ai** is an AI-powered Product Manager dashboard that helps hackathon teams instantly convert an idea into a complete, structured product plan.

It enables teams to move from **idea → execution-ready plan** in minutes.

---

## ✨ Features

HackathonPM.ai automatically generates:

- 📌 Product Overview
- 🗺️ Roadmap
- 🧪 MVP Plan
- 🧰 Tech Stack Suggestions
- 🔍 Critic Review
- 🎤 Presentation Script
- 🏗️ Architecture Diagram

---

## 🤖 AI-Powered Tools (Tambo Integration)

The platform includes **Tambo-powered AI tools** such as:

- 💬 AI Assistant Panel
- ✍️ Inline Section Improvements
- 🐞 Bug Fix Assistant

### Tambo Integration
The frontend integrates **Tambo (`@tambo-ai/react`)** using:
- `TamboProvider`
- `useTambo()`

This enables:
- AI assistant chat
- Inline content improvements
- Bug fixing & code review tools
